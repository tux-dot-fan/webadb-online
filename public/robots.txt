# ── robots.txt for webadb.online ─────────────────────────────────────────────
#
# Three sections:
#
#   1. Classic crawl rules — what each well-behaved web crawler is
#      allowed to fetch. We allow everything (no /admin paths exist,
#      and the dashboard renders client-side so crawlers only see the
#      landing page + blog).
#
#   2. AI bot policy — explicit directives for the AI-scraping bots
#      that read robots.txt to decide what to train on / cite. We
#      ALLOW training-use bots (GPTBot, ClaudeBot, Google-Extended,
#      CCBot, PerplexityBot, anthropic-ai, Applebot-Extended) and
#      explicitly cite llms.txt as the AI-optimized surface for
#      structured consumption. Block the legacy, ill-behaved scrapers
#      that don't respect crawl-delay or canonical hints.
#
#   3. Sitemap pointers — to the HTML sitemap (humans) and the
#      llms.txt / llms-full.txt (AI agents). Putting all three in one
#      file means an agent that fetches robots.txt and parses Sitemap
#      directives can immediately discover the structured surface.
#
# Last reviewed: 2026-08-20.
